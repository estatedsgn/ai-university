# AI Университет

Ранний MVP учебного сервиса: самостоятельное обучение, практика в небольшой видеогруппе и повторения в своем темпе.

[Публичный репозиторий](https://github.com/estatedsgn/ai-university) · [Демо в Higgsfield](https://ai-university.higgsfield.app) · [Самостоятельное развертывание](app/docs/deployment.md)

**Текущий адрес демо требует входа в Higgsfield.** При проверке запросы без авторизации получали HTTP 401 на уровне платформы. Для набора людей по обычной публичной ссылке можно развернуть приложение в собственном Cloudflare Workers по инструкции ниже.

## Что работает

- Создание комнат и приглашение по ссылке, до шести человек.
- Общая серверная очередь, поднятие руки, таймер, пауза и ручная передача слова.
- Камера и микрофон WebRTC; камера добровольна, микрофон включается пользователем в свой ход.
- Четыре сценария практики: активное слушание, уверенная речь, английский разговор, аргументация.
- Встроенный модуль активного слушания: семь этапов, цель, 15/30/60 минут и доля игровых заданий.
- Проверка знаний с неограниченными повторными попытками и объяснением ответа.
- План повторений через 1/3/7/14/30 дней, утренний обзор и месячная проверка.
- Заявки тестовой группы с согласием, выбором цели и формата.
- Карта 85 связанных тем: 65 математических, 10 финансовых и 10 биологических. Первые 20 математических тем содержат объяснения и серверные задачи; остальные отмечены как маршрут разработки.
- Диагностика, отработка и отдельная проверка переноса знания, новые варианты задач при повторных попытках, переходы по предпосылкам.
- Приём готового JSON-теста от агента без ключа модели; генератор тестов по тексту и образовательной ссылке через серверный OpenAI после настройки.
- Экспорт черновика программы с целями, длительностью активностей и связями тем.

## Ограничения MVP

Ведущий видеокомнат сценарный, анализ речи не подключён. Озвучивание, если включено, выполняет голос браузера. Для генератора тестов реализован серверный OpenAI API; он работает после настройки OPENAI_API_KEY и MATERIAL_IMPORT_TOKEN. До настройки доступны готовые математические задания и импорт тестов, подготовленных агентом.

Видеосвязь — peer-to-peer WebRTC с STUN, без TURN/SFU: в некоторых сетях связь не установится. Отключение микрофона выполняет клиент; измененный клиент может обойти это ограничение. Для серверного контроля публикации аудио нужен SFU.

Модуль активного слушания хранит прогресс в браузере. Попытки новой карты знаний сохраняются в D1 и связаны с анонимной HttpOnly cookie этого браузера, без учебных аккаунтов и синхронизации между устройствами. Потеря cookie означает потерю доступа к прежним попыткам. Обзоры показываются при открытии приложения; push/email/фоновые напоминания не подключены.

Быстрый ответ, таймер и высокий балл не доказывают отсутствие внешней помощи. Сервер скрывает ответы до отправки, выдаёт задания по одному и сохраняет рассуждения для последующей проверки. Статус готовности к следующей теме предварительный; импортированные тесты не проверены преподавателем. Ни эти результаты, ни экспорт программы не являются государственной аккредитацией.

## Локальный запуск

Код приложения находится в `app/`. Стек: React 19, TanStack Start, TypeScript, Cloudflare Worker, Durable Object `Rooms` и D1. Нужны Node.js 22 и Bun 1.4.2.

```sh
git clone https://github.com/estatedsgn/ai-university.git
cd ai-university/app
bun install --frozen-lockfile
bun run build
bunx wrangler@4.146.0 d1 migrations apply ai-university-db --local --config wrangler.jsonc
bunx wrangler@4.146.0 dev --config wrangler.jsonc
```

Открой адрес, который напечатает Wrangler, обычно `http://localhost:8787`. Сборка уже выполняет проверку TypeScript. Отдельная команда — `bun run typecheck`.

Локальный режим использует Cloudflare runtime через Wrangler; Vite dev сам по себе не предоставляет Durable Object и D1. В `app/wrangler.jsonc` заданы bindings `DB`/`ROOMS`; UUID базы — локальная заглушка. Для внешнего развертывания нужен реальный ID созданной D1 базы: [пошаговая инструкция](app/docs/deployment.md).

GitHub Actions проверяет установку по зафиксированному `bun.lock`, тесты графа/оценивания/импорта и сборку на Node.js 22. CI не развертывает приложение и не требует секретов.

## Данные

Видео и аудио не записываются. В D1 сохраняются заявки пилота, попытки диагностики и импортированные тесты. Материалы приватны по умолчанию; явно выбранный доступ по ссылке позволяет передать материал другим. Публичного API списка участников нет. Контактные данные, выгрузки заявок и runtime данные не должны попадать в публичный репозиторий.

Доступ в комнату — по UUID-ссылке. Право организатора определяется HttpOnly cookie, которую проверяет сервер.
