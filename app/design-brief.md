# AI Университет
Design read: спокойный цифровой кампус для взрослых, которые учатся через практику и диалог.
Concept spine: аудитория вокруг общего стола; каждый голос получает свое пространство.
Delivery tier: editorial, рабочий сервис.
Animation mode: non-animated — user picked Спокойный интерфейс без сложной анимации.
Palette: white #F7F9F8, jade #176B5B, coral #E65348, ink #263D36, mist #E9F1EC.
Type: system sans, доступное чтение кириллицы, сильная иерархия заголовков.
Chrome: левое меню кампуса, карточки программ, отдельный вид комнаты.
Primary CTA: создать комнату с минимальной формой имя/тема.
Secondary CTA: присоединиться по ссылке; набор в тестовую группу.
Signature: круг из мест вокруг символа диалога; очередь в комнате визуально передает слово.
Learning: семь стадий, гибкое время, игровой процент, повторения 1/3/7/14/30, месячная проверка.
Persistence: заявки D1; настройки и обучение в браузере; комнаты Durable Objects.
Accessibility: focus states, visible status text, reduced motion, media permissions on explicit action.
Assets: generation attempted; unavailable due Out of credits. SVG brand kit used as transparent fallback.
No fake people, counts, endorsements, AI assessment, recordings.
Moderator: scripted facilitator; no generative language model connected.
Video: peer WebRTC, STUN; no TURN or media-server mute enforcement.
