# Проверка MVP

Проверено 1 октября 2026 года перед первой публикацией.

- TypeScript и production сборка: `bun run build`, успешно.
- Зависимости: `bun audit`, 668 пакетов, известных уязвимостей не найдено.
- Учебный модуль: рендеринг на сервере, восстановление прогресса, сумма минут и расчет результата по фактическим ответам.
- Заявки: 44 проверки API и SQLite, включая валидацию, согласие, одинаковый ответ при повторном email и конкурентное ограничение частоты.
- Комнаты: 17 проверок серверной логики на модели Cloudflare runtime — права организатора, очередь, таймеры, лимиты, восстановление WebSocket и проверка Origin.
- Полный интерфейс: 13 проверок в двух независимых Chromium-контекстах с настоящим локальным Wrangler Worker и D1. Создание комнаты, приглашение, роли, очередь, обмен аудио/видеопакетами WebRTC, выключение микрофона при смене хода, отсутствие горизонтального переполнения на ширине 390px.
- WebRTC: mesh из шести участников; после исправления коллизии первоначальных offer — восемь повторных подключений через реальный Workers WebSocket с передачей аудио и видео.

Браузерные проверки используют искусственные устройства Chromium. Это проверка передачи медиапакетов, а не качества речи или связи у реальных людей. Не проверялись корпоративные сети без доступного peer-to-peer соединения, Safari/iOS и реальные групповые звонки на слабых устройствах. Эти случаи входят в пилот.

Локальная проверка сборки и runtime описана в README. Тестовые заявки и локальное состояние Wrangler не входят в исходники.
