# Учебный цикл MVP

Компонент: `LearningCycle({ onPractice: () => void })`, named export из `src/components/LearningCycle.tsx`. CSS импортируется внутри компонента, все классы имеют префикс `cycle-`.

Встроенный предмет — активное слушание. Материалы, сценарии и пять вопросов подготовлены заранее. Свободные ответы сохраняются для самооценки, не получают выдуманной оценки ИИ. Видеокомната открывается вызовом `onPractice`; компонент не заявляет, что сам соединяет участников или управляет чужими микрофонами.

## Этапы

1. Объяснение: дослушать, пересказать смысл, уточнить.
2. Практика: свободный ответ на сценарий или добровольный игровой вызов из трёх элементов; переход в комнату.
3. Усвоение: пересказ принципа своими словами и пример применения.
4. Повторение: самостоятельное извлечение трёх действий, затем открываемая опора.
5. Тест: пять сценарных вопросов. После отправки — выбранные ответы и объяснение каждого. Нет проходного порога; число повторов не ограничено.
6. Утренний обзор: повторение через 1, 3, 7, 14, 30 суток с фактического времени первого завершённого учебного теста. Просроченные обзоры остаются доступны. Самоотметка допустима только после наступления даты; свободное повторение доступно в любой момент.
7. Месячная проверка: через 30 суток после первого учебного теста либо последней месячной попытки. Это рекомендация, не блокировка: тест доступен раньше и повторяется неограниченно. Сравниваются фактические количества правильных ответов месячной попытки и последнего учебного теста; результаты не доказывают переноса навыка в реальный разговор.

Следующий этап можно открыть в любой момент; завершение отдельного этапа не выдаёт сертификат. Темп выбирает ученик. Будущие рекомендации преподавателя отдельно обозначены как план.

## Предпочтения и время

Вопрос «что хотите делать и зачем» помогает участнику зафиксировать свою цель; не отправляет сообщение посетителю. Письма и push отсутствуют. Нельзя собирать контакты и сообщать пользователю, что ему уже пишет ИИ.

Длительность — 15, 30, 60 минут. План: информация 17%, практика 33%, усвоение 17%, повторение 17%, тест 16%. Минуты округляются методом наибольших остатков, поэтому их сумма ровно равна длительности. Это план, не фактически затраченное время.

Игровая доля — 0–100% времени практики, по умолчанию 30%. Пользователь видит минуты игры и обычной практики, может переключить задание независимо от плана. Игра не обязательна; нет рейтинга, штрафов, streak или давления.

## Данные

`localStorage["ai-university:learning-cycle:v1"]` хранит только в этом браузере цель, настройки, заметки, самоотметки и собственные попытки. Синхронизации с аккаунтом, серверной базы, отправки третьим лицам и проверки личности нет. При недоступности хранилища выводится уведомление, а состояние работает в памяти.

Чтение и запись происходят только в `useEffect` после mount, поэтому серверный рендер не использует browser globals. Невалидный JSON и неизвестная версия безопасно отбрасываются; восстановленные попытки проверяются, балл пересчитывается по ответам. Пароли и конфиденциальные сведения вводить не следует.

## Проверка

Экспортированы `allocateSessionMinutes`, `quizCorrectCount`, `reviewDueAt`, `restoreCycleState` и `LISTENING_QUIZ` для проверки важных правил:

- для длительности 15/30/60 сумма целых минут ровно равна исходной; значения неотрицательны;
- правильные ответы [1, 0, 2, 1, 0] дают 5/5; [0, 1, 0, 0, 1] дают 0/5; пустая попытка не получает правильных ответов;
- обзор от `2026-10-01T08:00:00.000Z` на 1/3/7/14/30 сутки приходится на 2/4/8/15/31 октября в 08:00 UTC;
- некорректная дата возвращает null;
- повреждённый JSON, неверная версия, попытка без всех ответов не превращаются в результат; сохранённый фиктивный correct пересчитывается;
- в браузере заполнить цель и заметки, пройти тест, обновить страницу — состояние и фактический результат сохраняются;
- до отправки теста правильные ответы и объяснения не раскрыты; отправка без всех ответов выводит ошибку; после отправки возможно начать новую попытку;
- первый учебный тест запускает календарь, повторный не сдвигает дату начала;
- при недоступном localStorage можно выполнить задания, виден статус отсутствия сохранения;
- мобильная ширина 390px: поля, тест и календарь помещаются без горизонтального скролла; все элементы доступны с клавиатуры.

Для ускоренной проверки календаря можно подставить completedAt в localStorage на 31 день раньше текущего времени и обновить страницу. Не включать тестовые данные в стартовое состояние продукта.

## Секундомер

Явный локальный секундомер запускается только кнопкой «Старт», останавливается кнопкой «Пауза» и очищается кнопкой «Сброс». Измеряется прошедшее время в запущенном состоянии, отдельно от плановых процентов и минут. Показатель не означает измерение внимания или активности; он включает паузы в разговоре и время в фоновой вкладке. При выходе из модуля секундомер сбрасывается, не сохраняется в localStorage и не синхронизируется.

Проверка: нажать Старт, дождаться изменения 00:00, поставить Паузу и убедиться, что счётчик остановлен; Продолжить увеличивает то же значение; Сброс возвращает 00:00 и останавливает таймер.
