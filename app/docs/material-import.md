# Материал → черновик теста → проверка себя

MVP поддерживает два независимых пути:

1. **Готовый тест от человека или агента.** Вставьте JSON в «Материалы» и сразу запустите диагностику. Сервер проверяет структуру, сохраняет ключи ответов приватно и выдаёт вопросы через сервер оценки. Ключ модели и токен организатора для такого импорта через сайт не нужны.
2. **Учебный текст или ссылка → AI-черновик.** Организатор включает серверную интеграцию OpenAI и использует токен импорта. Ответ модели проходит ту же проверку структуры. Отсутствие настройки даёт честный HTTP 503; приложение не подменяет генерацию заранее написанными вопросами.

Импортированные тесты всегда имеют `reviewed: false`. Правильная структура не доказывает правильность формулировок или ответов. Преподавателю нужно проверить содержание. Результат такого теста помогает понять пробелы, но не открывает ступени проверенного учебного графа и не является документом об образовании или доказательством аккредитации.

## Настройка сервера

Из каталога `app` примените D1-миграции из `migrations` и привяжите БД как `DB`. Нужны обе новые миграции: `0002_learning.sql` для учебных сессий и общих лимитов, `0003_materials.sql` для материалов.

Для платной генерации настройте секреты в Cloudflare, **не в коде, GitHub, браузерном хранилище или чате**:

```sh
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put MATERIAL_IMPORT_TOKEN
```

Команды запрашивают значения в терминале. Создайте случайный токен минимум из 16 символов; рекомендовано 32 случайных байта. Длина допускается до 512 символов. `OPENAI_MODEL` — необязательная серверная переменная, по умолчанию `gpt-4.1-mini`. Приложение вызывает Responses API со структурированным JSON-выводом и `store: false`.

Исходный текст передаётся модели OpenAI для подготовки черновика. Не загружайте секреты или чужие персональные данные. Приложение не сохраняет исходный текст в D1; сохраняются учебное название, краткое описание, вопросник, безопасные метаданные источника и хеш владельца. Токен, ключ API и текст не выводятся в логи этой обработкой.

## Контракт HTTP

`POST /api/materials/import`, `Content-Type: application/json`.

```ts
type MaterialImportInput = {
  title?: string;
  track?: "math" | "finance" | "biology" | "custom"; // custom по умолчанию
  visibility?: "private" | "unlisted";             // private по умолчанию
  text?: string;
  url?: string;
  agentQuiz?: {
    title: string;
    summary: string;
    questions: {
      prompt: string;
      options: string[]; // ровно 4 разных варианта
      correctIndex: number; // целое 0..3
      explanation: string;
    }[]; // 5..10 разных вопросов
  };
};
```

Для генерации передайте **либо `text`, либо `url`**. Для готового теста передайте `agentQuiz`, без `text`; необязательная поддерживаемая `url` используется как метаданные, без загрузки страницы. Неизвестные поля отклоняются.

Пределы: JSON до 64 KiB, текст 100–12 000 символов, название 2–160, описание 10–1200, формулировка вопроса 10–800, вариант ответа 1–250, пояснение 5–1200. Вопросы и варианты должны быть различными, корректный индекс обязателен. Все пути используют общий атомарный лимит **10 импортов в сутки на IP**; хранится ежедневный хеш IP, а не исходный адрес. На локальном запуске без `CF-Connecting-IP` лимит разделяется всеми запросами с отсутствующим адресом.

Браузерный импорт готового JSON без токена требует точного `Origin` сайта. Генерация требует `X-Import-Token` и точного `Origin`; токен в интерфейсе живёт только в памяти текущей вкладки.

Внешний агент может отправлять `Authorization: Bearer <MATERIAL_IMPORT_TOKEN>` без `Origin`, если запрос не содержит браузерных `Sec-Fetch-*` заголовков. При переданном `Origin` он также должен точно совпадать. Не смешивайте оба заголовка токена. Для автоматизации без токена разрешён готовый JSON с точным `Origin`; это не даёт доступ к платной генерации.

Успех HTTP 201:

```json
{
  "material": {
    "id": "xxxxxxxx-xxxx-4xxx-xxxx-xxxxxxxxxxxx",
    "title": "Дроби",
    "summary": "Учебный черновик для проверки преподавателем.",
    "sourceUrl": null,
    "track": "math",
    "questionCount": 5,
    "createdAt": 1780000000000,
    "origin": "agent",
    "reviewed": false,
    "visibility": "private"
  }
}
```

Ответ устанавливает анонимную защищённую cookie владельца. Сохраняйте cookie при последующих запросах: она связывает материал и учебную сессию с браузером/агентом, не является учётной записью. Очистка cookie лишает доступа к приватному материалу; восстановление и синхронизация между устройствами пока не реализованы.

`GET /api/materials/:id` возвращает `{ material }` с той же структурой. `private` доступен только владельцу, `unlisted` — тому, кто знает UUID. Ответ не содержит исходный текст, хеш владельца, вопросы, ключи, правильные индексы или пояснения. Ссылка без списка не делает тест проверенным или аккредитованным.

Для начала используйте `POST /api/learning/assessments` с `{ materialId, mode: "diagnostic", timed: true }` и той же cookie. Ответ содержит `{ assessment }` с одним текущим вопросом. Передайте ответ через `POST /api/learning/answers`: `{ assessmentId, questionId, answer, reasoning? }`; для выбора `answer` — точный текст выбранного варианта. При включённом таймере новый вопрос активируется отдельно через `POST /api/learning/assessments/:id/next` с `{}`. Учебные POST-запросы также требуют точного `Origin`; продолжайте отправлять cookie владельца.

Ошибка: `{ "error": "Текст на русском", "code": "стабильный_код" }`. Типовые статусы: 400 формат/источник, 401 токен, 403 Origin, 413 размер, 415 тип тела, 429 дневной лимит с `Retry-After`, 502 модель, 503 настройка или хранилище. Ошибки не раскрывают ответы модели, SQL, исходный текст или секреты.

## Пример агента

Сохраните подготовленный тест в `quiz-import.json`. Пример полностью самодостаточный и содержит учебные вопросы, требующие редакторской проверки:

```json
{
  "track": "math",
  "visibility": "private",
  "agentQuiz": {
    "title": "Знакомство с дробями",
    "summary": "Черновик простых вопросов по дробям. Преподавателю нужно проверить формулировки и ключи.",
    "questions": [
      {"prompt":"Чему равно значение дроби 1/2?","options":["0,5","0,2","2","1"],"correctIndex":0,"explanation":"Деление одного на два даёт половину, то есть 0,5."},
      {"prompt":"Какая из дробей равна одной второй?","options":["2/4","1/4","3/4","2/3"],"correctIndex":0,"explanation":"Если числитель и знаменатель 1/2 умножить на два, получится 2/4."},
      {"prompt":"Чему равно 1/4 + 1/4?","options":["1/2","1/8","2/8","1/4"],"correctIndex":0,"explanation":"При равных знаменателях складываем числители: 2/4 = 1/2."},
      {"prompt":"Какая дробь больше: 1/3 или 1/2?","options":["1/2","1/3","Они равны","Сравнить невозможно"],"correctIndex":0,"explanation":"При равных положительных числителях дробь с меньшим знаменателем больше."},
      {"prompt":"Чему равна половина числа 10?","options":["5","2","10","20"],"correctIndex":0,"explanation":"Умножение 10 на 1/2, или деление 10 на 2, даёт 5."}
    ]
  }
}
```

Обычный импорт готового JSON без серверных секретов:

```sh
curl --fail-with-body \
  -c learner.cookies \
  -H 'Content-Type: application/json' \
  -H 'Origin: https://YOUR-UNIVERSITY.example' \
  --data-binary @quiz-import.json \
  https://YOUR-UNIVERSITY.example/api/materials/import
```

Для платного импорта внешний агент читает токен из своего секретного хранилища/переменной `AIU_IMPORT_TOKEN`, не из репозитория. Не включайте трассировку shell и не публикуйте сформированную команду с секретом:

```sh
curl --fail-with-body \
  -b learner.cookies -c learner.cookies \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer ${AIU_IMPORT_TOKEN}" \
  --data-binary @text-import.json \
  https://YOUR-UNIVERSITY.example/api/materials/import
```

`text-import.json`: `{ "text": "...от 100 до 12 000 символов учебного материала...", "track": "math" }`. Подставьте настоящий текст; многоточие в примере само по себе недостаточно.

## Поддерживаемые ссылки

Только HTTPS без логина/пароля и нестандартного порта, на явном списке публичных образовательных доменов:

- `wikipedia.org` и его поддомены;
- `openstax.org`, `www.openstax.org`;
- `math.libretexts.org`;
- `ocw.mit.edu`;
- `khanacademy.org`, `www.khanacademy.org`.

Сервер проверяет каждый редирект, разрешает максимум три перехода, ограничивает чтение 256 KiB и общее ожидание 10 секунд. Поддерживаются `text/html` и `text/plain`; скрипты/стили удаляются, в модель идут первые 12 000 символов текста. URL в публичных метаданных не содержит query-параметры и фрагмент. Страница, зависящая от JavaScript, может потребовать вставки текста.

Другие домены, PDF, приватные ссылки и закрытые страницы сейчас не загружаются. Их текст можно вставить вручную. Это конкретный ограниченный список источников, а не универсальный безопасный загрузчик интернета. Источник передаётся модели как недоверенные данные; структурированный вывод и проверка формата не заменяют предметную проверку преподавателем.

## Проверка

`bun test src/lib/materials.server.test.ts` выполняет проверки API с поддельной D1 и поддельным `fetch`: анонимный/защищённый импорт, Origin и Bearer, границы JSON, приватный/доступный по ссылке материал, исключение ответов из метаданных, лимит, HTTPS-список и каждый редирект, тип/объём источника, изоляцию текста и отказ при неправильном ответе модели. Реальное применение SQLite-миграций и учебные сессии проверяются интеграционными тестами сервера оценки. Тесты не требуют ключа OpenAI и не утверждают педагогическую валидность вопросов.
