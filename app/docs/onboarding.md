# Первое интервью и учебный маршрут

В разделе «Мой учебный маршрут» ученик отвечает на пять коротких вопросов: цель своими словами, предмет, самооценка опыта, время и предпочтительный формат.

## Правила
- Маршрут рассчитывается по реальной карте `src/lib/curriculum.ts`. Явно выбранный предмет важнее распознанных ключевых слов.
- Это предварительная рекомендация, не измерение знаний или личности. Самооценка опыта не выдаёт статус освоения темы.
- Кнопка «Пройти первую диагностику» открывает реальную тему с готовыми задачами в существующем KnowledgeHub.
- Математика содержит готовые проверки; финансы и биология пока показаны как планы. Поэтому первая проверка для таких треков относится к математическим предпосылкам.
- Источники материалов: существующие темы карты и раздел «Свои материалы» в KnowledgeHub. Импорт из OpenStax, MIT OCW, Khan Academy, LibreTexts, Wikipedia уже поддерживается отдельно через MaterialsStudio; интервью не притворяется, что автоматически изучило все эти источники.

## Данные и ИИ
Ответы сохраняются в `localStorage["aiu-onboarding-v1"]` только после завершения интервью; есть кнопка полного удаления этого локального профиля. В анкете нет имени, телефона, почты или даты рождения, запрашивать их не следует.

По умолчанию работает детерминированный алгоритм на клиенте, без внешних запросов. Отдельная кнопка «Уточнить маршрут с ИИ» отправляет ответы на `POST /api/onboarding/recommend` только по инициативе ученика. Сервер проверяет Origin, размер тела, тип данных, лимит запросов через D1, использует `OPENAI_API_KEY` и `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Запрос к Responses API ставит `store: false`, ограничивает структуру результата и не даёт модели выбирать несуществующие темы. Для запуска нужны настроенные `OPENAI_API_KEY` и D1. Без настроенного ИИ основной маршрут и все тесты продолжают работать.

Внешний сервис получает ответы на вопросы при явном запросе AI-анализа. Для набора детей в настоящий пилот отдельно потребуются понятные правила согласия, обработки данных и проверки материалов педагогами.

## Проверки
`bun test src/lib/onboarding.test.ts` и стандартный CI `bun test src/lib` / `bun run build`. Проверить в браузере: пройти интервью, перезагрузить страницу и восстановить маршрут; открыть рекомендуемую тему, удалить ответы и начать заново; при отсутствии ключа получить понятное сообщение, не теряя маршрут.
